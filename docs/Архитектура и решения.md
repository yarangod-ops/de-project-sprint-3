# Как устроена загрузка

Данные проходят через API и CSV в `staging`, затем в таблицу продаж `mart.f_sales` и недельную витрину `mart.f_customer_retention`. Один и тот же код загрузки используется в Airflow и при запуске через Python.

При первом запуске я получаю начальный отчёт и сохраняю его идентификатор в `etl.report_state`. Следующие дни загружаются через `get_increment` для этого отчёта.

## Продажи

Одна строка в `f_sales` — одна операция из исходного файла. Покупка и возврат с одним `uniq_id` хранятся отдельно: в ключ также входят дата и статус. В старых файлах без статуса я подставляю `shipped`.

У возврата сумма и количество отрицательные. Для денег использую `Decimal` в Python и `NUMERIC(18,2)` в PostgreSQL.

## Недельная витрина

Показатели считаю отдельно для клиента, недели и `item_id`. Одна операция `shipped` считается одной покупкой. Количество единиц товара и возвраты не увеличивают число покупок.

- `new` — одна покупка за неделю;
- `returning` — несколько покупок;
- `refunded_customer_count` — клиенты хотя бы с одним возвратом;
- `customers_refunded` — количество операций возврата.

Клиент с возвратом может одновременно относиться к `new` или `returning`. Доход этих групп считаю по покупкам до вычета возвратов, а общую выручку с возвратами — в `f_sales`.

В `period_id` хранится номер ISO-недели. Поле `week_start` разделяет одинаковые номера недель разных лет; строка витрины определяется парой `(week_start, item_id)`.

## Исправление дня

Сначала я скачиваю и проверяю все файлы. Затем в одной транзакции заменяю выбранный день в `staging` и продажах, пересчитываю всю затронутую неделю и записываю результат загрузки в `etl.load_audit`.

Если SQL завершается с ошибкой, изменения откатываются. Если API не отдал файл, прежний день остаётся. Корректный пустой файл означает, что операции за день нужно удалить. Одновременные загрузки в БД выполняются по очереди через блокировку транзакции.

Файл миграции есть в `migrations/001_schema.sql` и внутри пакета DAG. Содержимое одинаковое: копия в пакете нужна для переноса загрузки в Airflow.
