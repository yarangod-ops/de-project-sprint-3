# Проект по автоматизации подготовки данных

Годияк Ярослав Андреевич, М25-555, М255948.

## Этап 1. Продажи и возвраты

Я добавил обработку возвратов: покупки увеличивают выручку, возвраты её уменьшают. Старые файлы без статуса тоже загружаются, прежние продажи сохраняются.

На контрольных данных проверил количесто записей и сумму. Получил ожидаемые 11 операций и 1350 рублей.

## Этап 2. Отчёт по клиентам

Я собрал недельный отчёт по каждому товару: сколько клиентов сделали одну покупку, несколько покупок или оформили возврат. Добавил суммы покупок и количество возвратов.

Проверил эти случаи на контрольных данных. Получил четыре строки отчёта, все показатли совпали с ожидаемыми. Отдельно убедился, что возврат не считается второй покупкой.

## Этап 3. Повторная загрузка

Я сделал повторную загрузку выбранного дня с пересчётом всей недели. Теперь можно загрузить исправленные данные без дублей.

Повторил загрузку — количество строк и суммы не изменились. Затем добавил заказ на 70 рублей: получил 12 операций и 1420 рублей вместо 11 и 1350. Также проверил изменение и удаление заказа, а при ошибке загрузки прежние данные сохранились.
